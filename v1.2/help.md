# 像素涂鸦 · 使用说明

一个放在手机上的像素画工具。核心是 **练配色** —— 所以颜色这块（卡槽、配色库、明暗色阶）
做得比较重，别的功能都尽量精简。

> **练配色的小建议**：别急着用自己顺手的颜色。先在「配色库」里挑一组现成的，
> 只用这一组里的颜色画完一张，比随便挑色进步快得多。

---

## 先认认地方

```
   ┌──────────────────────────────────────────────────┐
   │  顶栏：[菜单] [撤销][重做]   [图层][播放]  [卡槽][网格][⋯]  │
   ├──────────┬──────────────────────────┬────────────┤
   │          │                          │            │
   │  左侧     │         画    布          │   调色板    │
   │  工具栏   │    单指画 · 双指缩放/平移  │  （默认收起）│
   │  13 个    │                          │            │
   │  工具     │                          │            │
   │          │                          │            │
   ├──────────┴──────────────────────────┴────────────┤
   │  底栏： PICO-8 系统 16   [图层][调色][配色库][清空]  [当前色] │
   └──────────────────────────────────────────────────┘
```

> 左边一竖条是**工具栏**（13 个工具，点顶栏第一个按钮能收起来）。
> 右边是**调色板**，默认藏起来，点底栏「调色」才滑出来。
> 底下那条是**卡槽**（放正在用的颜色）。

### 顶栏

从左到右 8 个按钮：

| 位置 | 图标长得像 | 作用 |
|---|---|---|
| 1 | 三条横线 | 收起 / 展开左侧工具栏 |
| 2 | 弯箭头（左） | 撤销（**24 步**） |
| 3 | 弯箭头（右） | 重做 |
| 4 | 两层叠起来的菱形 | 图层（**漂浮窗**形态，飘在画布上，能拖走） |
| 5 | 三角形（播放） | 播放动画（把图层当帧来播） |
| 6 | 上下箭头 | 收起 / 展开底部卡槽 |
| 7 | 四个小方块 | 像素网格开关 |
| 8 | 三个点 | 菜单（新建 / 调整画布 / 导出 / **工作区** / 帮助…） |

> **为什么工作区不放顶栏**：手机屏窄，顶栏塞太多按钮会把「网格」和「⋯」挤出屏幕外，
> 想点都点不到。所以创建 / 导入 / 打开全在**「⋯」菜单的「工作区」区块**里。

### 底栏

| 按钮 | 作用 |
|---|---|
| `图层` | 图层（**抽屉**形态，从下面升上来） |
| `调色` | 右侧调色板，点右上角的图钉可固定 |
| `配色库` | 系统调色板 / 我的卡槽，整组切换的地方 |
| `清空` | 清空**当前图层**（别的层不受影响） |
| 一个圆的色块 | 当前颜色 |

## 画布上的手势

| 手势 | 效果 |
|---|---|
| **单指拖** | 用当前工具画 |
| **双指捏合** | 缩放视图 |
| **双指拖** | 平移视图 |
| **铅笔工具 + 手指拖** | 画画 |

选了 **缩放** 工具后，单指拖就是平移视图（不用再撑两根手指）。

## 改工具参数：双击左侧图标

**双击**左边那个工具的图标 = 展开 / 收起它的参数面板（画面顶部那条）。

> **注意**：双击只对**正在用的那个工具**生效。
> 双击一个还没选中的工具，第一下只是「选中它」，得点第三下才算双击。
> 这是故意的 —— 参数是给「我正在用的东西」调的，不该跳到一个没在用的工具上去。

## 工具（13 个）

### 画的东西

| 工具 | 一句话 | 参数 |
|---|---|---|
| **铅笔** | 一笔一笔画 | 笔刷大小 1/2/3/4/6/8、左右对称 |
| **橡皮** | 擦成透明（不是擦成白色） | 笔刷大小 |
| **填充** | 一片同色区域一次填满 | 整片连续区域 / 整个选区 |
| **喷枪** | 喷出疏密不匀的点，做质感和渐变 | 喷幅 2/4/6/10、密度 疏/中/密 |
| **直线** | 按住拖出一条直线 | 粗细 1/2/3、左右对称 |
| **曲线** | 两种画法，见下 | 画法 简单/自由、粗细 |
| **矩形** | 拖出一个矩形 | 填充、描边（两个独立开关） |
| **椭圆** | 拖出一个椭圆 | 同上 |

**矩形 / 椭圆的两个开关**能各自勾，也能一起勾：

| 填充 | 描边 | 画出来 |
|---|---|---|
| ✓ | | 实心一块 |
| | ✓ | 空心一圈黑边 |
| ✓ | ✓ | 实心 + 外面一圈黑边（黑边是额外多一圈，不占形状自己那圈） |
| | | 一个空心的线框 |

**曲线有两种画法**：

```
简单（只能往一边弯）        自由（能掰出 S 形）
  ① 拖出直线松手              ① 拖出直线松手
  ② 再拖一下掰弯              ② 线上自动打 5 个点
  ③ 松手就好，不用点完成       ③ 拉蓝色小方块：拉中间出 C 形，
                                两个四分点往相反方向拉出 S 形
                              ④ 点「完成」落定
```

> 自由画法**就这 5 个点，不能再加** —— 能随便加的话点会越拖越多，线越拖越乱。

### 调整和取色

| 工具 | 一句话 |
|---|---|
| **选区** | 框出一块地方，之后的操作只在这一块里生效 |
| **移动** | 搬动画面里的东西 |
| **取色** | 点画面任意像素，取它的颜色当当前色 |
| **描边** | 给选区里的东西加一圈**纯黑**边 |
| **缩放** | 放大缩小视图、适应屏幕、居中画布、网格开关 |

**移动工具**：没选区就**整幅一起搬**；先用选区框好，搬的就只有框里的。
图层锁住的那些层会**原地不动**（详见「图层」一节）。

**描边工具**：没有选区时它是**灰的**，点不动。想给谁描边，先用选区框住谁 ——
不然一点画面，画布上每个东西都被描一圈。颜色固定纯黑，不用选色。

## 选区

选区的三种形状：

| 形状 | 怎么选 |
|---|---|
| **矩形** | 拖出一个框 |
| **椭圆** | 拖出一个椭圆范围 |
| **魔棒** | 点一下，自动认出**连成一片的同色区域** |

四种模式：新建 / 加上 / 减去（后两个用来拼出不规则的形状）。

框好之后画面底部会出现一条操作按钮：

```
复制  剪切  粘贴  翻转  填充  删除  取消
```

| 按钮 | 作用 |
|---|---|
| 复制 / 剪切 | 把选区里的内容存起来（剪切还会擦掉原处） |
| 粘贴 | 存起来的东西可以反复贴 |
| 翻转 | 左右镜像翻过来 |
| 填充 | 用当前色填满整个选区 |
| 删除 | 清掉选区里的像素 |

> 有选区时，**铅笔 / 橡皮 / 填充 / 喷枪都会被限制在选区里** ——
> 多画一笔超出边界也不会画到外面去。这个很好用，画某个形状的局部时可以放心大胆地涂。

## 图层

每一层有自己的像素，互不干扰。画错了只毁一层，别的层没事。

### 两个入口，同一个东西

| 入口 | 形态 | 特点 |
|---|---|---|
| 底栏 `图层` | **抽屉** | 从下面升上来，信息最全（每层带名字、眼睛、锁、删除） |
| 顶栏第 4 个图标 | **漂浮窗** | 飘在画布上，不挤画布，能拖到任意位置，能收成一小条 |

两个共用同一个开关，所以**天然互斥** —— 打开一个，另一个自动收起。

### 漂浮窗怎么摆弄

```
   ┌───────────────────────────┐
   │  ⋮⋮   图层        8   －   │  ← 这一整条都能按住拖
   ├───────────────────────────┤
   │  [缩略图] 图层 1  👁  🔒   │
   │  [缩略图] 图层 2  👁  🔒   │
   │  [缩略图] 图层 3  👁  🔒   │  ← 最多露出 5 层
   │  [缩略图] 图层 4  👁  🔒   │     第 6 层起用滑块滑（右边那条细蓝条）
   │  [缩略图] 图层 5  👁  🔒   │
   │        ⋮ 还能往下滑 ⋮      │
   ├───────────────────────────┤
   │   ＋新建   ↑   ↓   删      │
   └───────────────────────────┘
```

| 想干嘛 | 怎么做 |
|---|---|
| **收成一小条** | 点右上角 `－` |
| **展开回来** | 点那一小条（点一下就行，不用点哪儿特定的） |
| **整个收掉** | 点顶栏第 4 个图标（不用找 ✕） |
| **挪位置** | 按住**标题栏任意一处**上下拖（⋮⋮ 只是个「这里能拖」的提示） |

> **最多露出 5 层** —— 超过就出滑块。这是为了不让漂浮窗一路往下长、把画布盖满。
> 收起来的那一小条**没有 ✕**：想整个收掉直接点顶栏那个图层按钮，一个入口就够，
> 小条上再放个 ✕ 是多余的，还占地方。

### 每一行长这样

```
   ┌─────────────────────────────────────────────────┐
   │  1  [缩略图]   图层 1              眼睛   锁   删  │
   │                当前 · 可编辑                      │
   └─────────────────────────────────────────────────┘
      ↑              ↑                    ↑    ↑    ↑
     第几层       层的名字              显示 锁定 删除
```

| 那个小图标 | 名字 | 作用 |
|---|---|---|
| 眼睛形状 | **眼睛** | 显示 / 藏起这一层（藏起来不显示，也不参与播放） |
| 小锁头形状 | **锁** | 锁住：**画不上去、移动带不走、选区也选不中** |
| 叉叉形状 | **删除** | 删掉这一层（至少留一层，最后一层删不掉） |

### 新建的层排第几号

新层的编号 = **现存「图层 N」里最大的那个 + 1**，不是一路往上加的计数。

所以：有 1 号 → 新建得 2 号 → **删掉 2 号 → 再新建还是 2 号**，不会跳到 3 号。

改过名的层（比如叫「天空」）不参与编号，也不会被顶掉。

### 改名字

**点那一层的名字**，它就当场变成一个输入框：

- 回车，或者点一下别处 = 存下
- `Esc` = 反悔，当没改过
- 一个字不剩 = 也算没改（不会变成空名字）

名字最多 16 个字，超了会自动截掉。

### 排序：长按拖

**长按某一层 0.45 秒**，它就浮起来跟着手指走，底下会拉出一条蓝线告诉你「会插到哪儿」：

- 松手时手指落在目标层的 **上半** → 插到它**上面**
- 松手时手指落在目标层的 **下半** → 插到它**下面**

只挪一格的话，用底下的 `↑` `↓` 更快。

### 新建的层排在最下面

点 `＋ 新建`，新的一层**加到最下面**，并且立刻变成当前层（接着就能画）。

> 这是为了配合作画顺序：**播放动画时帧是从上往下播的**，新加的一层就是「下一帧」，
> 排在最下面才对。要是加到最上面，每次新建都会把 1 号图层往下挤一格，
> 画到第四帧时顺序全是反的。

### 锁定之后各种工具的联动

| 工具 | 锁住当前层 |
|---|---|
| 铅笔 橡皮 填充 喷枪 直线 曲线 矩形 椭圆 描边 | **画不上去**（会提示先解锁） |
| 移动 | 锁住的层**原地不动**，没锁的一起动 |
| 选区 | 锁住的层**选不中** |

## 播放动画（序列帧）

**一帧就是一图层**，不用另外学「帧」这个概念。点顶栏那个三角形按钮就能播。

### 播放条是个能拖着走的小窗

```
     ┌────────────────────────────────────────────┐
     │  ⋮⋮    播放  暂停   [12 ▾]   1 / 4    关闭   │
     └────────────────────────────────────────────┘
       │       │            │        │        │
       │       │            │        │        └ 收起来，停止播放
       │       │            │        └ 第几帧 / 共几帧
       │       │            └ 当前帧率（点它拉出下面那一小条）
       │       └ 播放 / 暂停，亮着的那个 = 现在的状态
       └ 长按这里把整个窗拖到任意位置（位置会记住）
```

点开帧率之后，紧贴着下面长出这一条：

```
     ┌────────────────────────────────────────────┐
     │  ⋮⋮    播放  暂停   [12 ▾]   1 / 4    关闭   │
     ├────────────────────────────────────────────┤
     │      2      6      12     24      自由       │
     └────────────────────────────────────────────┘
```

播放时各项工作的方式：

- **第 N 帧只显示第 N 层** —— 一张张图片翻过去，**不叠加**。
  所以每一层都要画完整的画面，别指望上一层的内容会留着。
- 只播**可见**的层（眼睛关掉的那层不参与）
- 面板里从上往下播：**第 1 层先播**
- 播到哪一层，那一层就变成当前层 —— 暂停之后直接落笔就画在那一帧上

### 帧率

点主条上那个 `[12▾]`，紧贴着拉出一小条：

```
2   6   12   24   自由
```

「自由」可以自己输 **1 ~ 60** 之间的任意帧率（四档不够用时用它）。
换帧率不用先暂停，立刻生效，位置也会记住。

> 播放条被拖到画面最下面时，帧率那一条会自动翻到播放条**上面**长出来，不会掉出屏幕。

## 颜色

颜色这块是重点，东西都在底下。

### 底栏卡槽：临时放几个正在用的颜色

| 操作 | 效果 |
|---|---|
| 点 + 号空位 | **只把调色板拉出来**（不会顺手加颜色） |
| 点已有颜色 | 取它来用（卡槽本身不动） |
| **长按**某一格 | 删掉这一格 |

末尾只留 **1 个空位**（以前是两个）。点它不会立刻加颜色 —— 空位就在颜色堆最右边，
手指一滑容易点到，稀里糊涂多一个颜色还得长按删掉。加颜色统一走右边那条路：

> 调色板 → 点 `＋` 进**临时卡槽** → 攒够了点 **加入卡槽** 送过来

系统卡槽是**只读**的。想存自己的颜色 → 配色库 → 我的卡槽。

### 拖着色块走（换个地方待着）

卡槽第一格有个 `⋮⋮` 手柄：

| 手势 | 效果 |
|---|---|
| **长按 300ms 再拖** | 整块颜色跟手指走，丢到屏幕**上 / 下 / 左 / 右**任一边吸住 |
| **双击**手柄 | 收进手柄里 / 再吐出来（收起来不等于取消吸附） |

吸走之后底部只剩菜单行，画布能大一圈。

### 配色库：整组地换

点底栏 `配色库`：

- **系统调色板** —— 现成的经典配色（PICO-8、Game Boy、Sweetie 等），**只读**
- **我的卡槽** —— 自己攒的，能建很多个、能命名、能增删颜色

> 挑一组喜欢的作为整张画的用色范围，是练配色最省劲的办法。

### 调色板：调当前色

点底栏 `调色`，从右边滑出 HSV 调色盘。点右上角那个**图钉**可以固定住不让它划回去。

#### 颜色配比

5 档，从左到右就是一条明暗阶梯：**描边 → 暗部 → 固有色 → 亮部 → 高光**。

- **固有色** = 你当前在用的前景色，另外 4 档跟着它变
- 点任意一格就把它拿来用 —— 上阴影点左边两格，提高光点右边两格
  （当前用的是哪个颜色，看底部工具栏那个当前色图标）

##### 什么时候会换成新的一套

规矩只有一条：**你选的颜色还在这 5 个里，配比就不动**。

| 你干了什么 | 配比 |
|---|---|
| 点这 5 格里的任意一格 | **不动**（你只是在这一套里换档） |
| 吸管吸画面上的颜色 | 吸到的还是这 5 个之一 → **不动** |
| 点卡槽里恰好是这 5 个之一的颜色 | **不动** |
| 拖色盘 / 色相条调出一个新颜色 | **换成新的一套** |
| 手输一个不在里头的 HEX | **换成新的一套** |

所以画的时候放心在这 5 个之间切来切去，挑好的一套不会被自己点没。
真想换整套，去调色板调个新颜色就行。

#### 临时卡槽

画布旁边临时攒颜色的小格子，攒够了再一次性交给卡槽。

- 点末尾那个 `＋` 空格：把当前色加进来
- 点已有格子：取它的颜色来用
- 长按某一格：删掉它
- 点 `＋` 后面那个 🗑 **垃圾桶**：一次全清（本来就是空的就不吭声）
- 点 `加入卡槽`：弹窗问你放哪儿
  - **新建我的卡槽** —— 用这些颜色新建一个卡槽，建好就直接用它
  - **直接载入当前卡槽** —— 塞进现在正在用的那个，替掉它原来所有的颜色
    （系统卡槽只读，这一项会灰掉）

颜色**送出去之后临时卡槽就空了**（不管送到哪儿）—— 已经载入的东西还留在里面，
下次一不小心又加一遍，等于没送。

#### 把这两块摘出去，变成悬浮条

`颜色配比` 标题左边那个「小窗＋箭头」的图标，和调色板头部那个「三横」图标，点一下就把那块从面板里**摘出来**，变成浮在画面上的一条。

| 想干嘛 | 怎么弄 |
|---|---|
| 挪位置 | **只能拖最左边那条带 6 个点的把手**，拖别处不会动窗 |
| 收 / 放 | 点一下把手：整个窗**只收宽度、高度不变**，再点一下吐回来 |
| 拼成一整块 | 上下两个窗靠近 24px 以内会**自动吸上**，拼完像一个整块一起动 |
| 拆开 | 拼着的时候**双击**把手 —— 会真的弹开一段距离，手指一碰不会再黏回去 |
| 上下换个儿 | 拼着的时候，拖上面那个往对方那边推过 60px |

悬浮条挡路了就把它拖到一边；真的用不着了，再点一次面板里那个图标就收回来了。

## 菜单：五件事分五个格子

以前是「⋯」一点，所有东西从上往下排一条长队。现在是**两级**：一级只看一行，点进去才是内容 —— 跟手机系统里的设置一个路子。

```
┌──────────────────────────────┐
│ ▣  画布            32 × 32  › │
│ ▤  导出          PNG/GIF/ZIP › │
│ 🗀  工作区          默认工作区 › │
│ ⚙  设置                 1.2  › │
│ ?  帮助              说明书   › │
└──────────────────────────────┘
```

右边那行小字是**当前状态**（画布尺寸 / 工作区名 / 版本号），不用点进去就能看到。
二级左上角有个 `‹` 返回；手机上按**返回键**也是先退回一级，退回一级后再按才关掉菜单。

| 格子 | 里面有什么 |
|---|---|
| **画布** | 新建（16 / 32 / 64 / 256 / 512 或自己填尺寸，最大 512×512）· 调整画布大小（拖四条边，**已有画面不会被裁掉**）· 清空当前图层 |
| **导出** | 静态图：所有可见层合成一张 PNG，1 / 4 / 8 / 16 倍（按钮上写出导出来多大）· 动图：选格式 GIF / APNG + 模式 A 合成 / B 分图层 ZIP。详见下面「导出 / 工作区」 |
| **工作区** | 创建 / 导入 / 打开 / 导出 ZIP，见下面「菜单里的「工作区」区块」 |
| **设置** | 见下 |
| **帮助** | 就是这份文档（全屏显示） |

### 设置

| 分区 | 项目 | 说明 |
|---|---|---|
| 通用 | 音效 / 震动 | 开关（**目前只预留**，见下面说明） |
| 画面 | 网格 | 像素网格开关（顶栏那个四个方块的图标也是它） |
| 画面 | 让画布适应屏幕 | 缩放回到刚好装下整张画布 |
| 更新 | 启动时检查更新 | 打开后偶尔会连一下网，只在有新版时给个小红点 |
| 更新 | 检查更新 / 立即更新 | 见下面「更新」一节 |
| 关于 | 版本 · 资源 | 当前跑的是 v1.2 还是补丁、资源来自内置还是在线 |
| 关于 | 下载最新安装包 | 跳到下载页 |

> **音效和震动现在是灰的**：能开能关、也记得住，但暂时不会真的响 —— 这两个开关是给后面预留的，先把位置占好。
> 清图层为什么要单独放在「画布」里：多层的时候「一键清空」会把别的层一起抹掉，太危险。一层层清是有意的，而且**还能撤销回来**。

## 导出 / 工作区

这次加的是「把画好的东西存出来」+「在手机里有个专门的地方放这些图」。**都在「⋯」菜单里**。

### 菜单里的「工作区」区块

点顶栏 ⋯ → 菜单里找到「工作区（创建 / 导入 / 打开）」：

| 按钮 | 干嘛的 |
|---|---|
| **＋ 创建** | 建一个**工作区**（就是个文件夹）。当前画布会收进这个新工作区当初始内容，之后你画的东西、导出的图都归它管 |
| **导入图片** | 从**手机相册**选一张图 → 画布**直接变成这张图**（画布尺寸跟着图片走，最大 1024×1024，再大自动缩）。适合拿现成的图来改色、修细节 |
| **导出工作区 ZIP** | 把当前工作区里的图拼成一个带文件夹的压缩包下载 |
| 工作区列表 | 每个工作区一行，右边有 **打开** / **删**。点「打开」就切到那个工作区 |

> 现在工作区是**存在本机浏览器里**（IndexedDB），自动保存，关掉再开还在。
> 真正装机成 APK 之后，这一步会换成手机里的真实文件夹。

### 导出（在菜单里）

点顶栏 ⋯ → 菜单分两块：**静态图** / **动图**。

> **导出的图怎么存下来**：预览下面那个「**保存 / 分享**」按钮。
> 手机 App 里点它会呼出系统分享面板 —— 选「保存到相册」「微信」「发到电脑」都行；
> 在网页里点它就是下载到手机。

**① 静态图**：不管你画了多少图层，全部合成**一张 PNG**。
倍数选 1 / 4 / 8 / 16（按钮上直接写着导出来多大，超过 4096 的档位不显示）。

**② 动图**：先选**格式**，再选**模式**：

| 格式 | 说明 |
|---|---|
| **GIF** | 到处都能动，老设备也认 |
| **APNG** | 浏览器 / 相册里会动，画质更好（本质上还是 PNG，只是带了帧） |

| 模式 | 开关 | 导出什么 |
|---|---|---|
| **A · 合成动图** | 勾上 | 一个动图文件（GIF 或 APNG），把每层当一帧拼起来 |
| **B · 分图层** | 勾上 | 每层一张 PNG，打包成 **ZIP** 下载（解压就是一张张静图） |

> 动图至少得有 **两层**（一帧就是一图层）。不够就先去图层里加一层当下一帧。
> 帧顺序 = 图层面板从上往下，跟「播放动画」一致；关掉眼睛的那层不进动图。

### 归档到工作区

不管静态图还是动图，**导出时图都会顺手归档进当前工作区的两个文件夹**：

```
工作区「我的工作区」
   ├── static/        静图（全部图层合一的那张）
   └── anim/          动图（A 模式那个 GIF/APNG）
                    + 分图层（B 模式每层一张 PNG + 那个 ZIP）
```

想一次性把整个工作区搬走 → 菜单里「**导出工作区 ZIP**」：把 static/、anim/ 拼成一个带文件夹的压缩包下载。

## 一些实用小窍门

**画图案 / 对称图形** —— 铅笔打开「左右对称」，画一半另一半自动有。

**改某个地方的颜色** —— 魔棒选中那一片 + 填充。
不用小心翼翼地描边，同色连成一片的地方魔棒一次就选中了。

**局部重画不怕画出去** —— 先用选区框住要改的地方，
之后铅笔橡皮都只在选区里生效，超出边界的笔画不会被画上去。

**做渐变 / 做质感** —— 喷枪比铅笔好使：密度调「疏」、多喷几层，
交界处会自然混出颗粒感。

**画错了只毁一层** —— 复杂的地方单独开一层画。
画砸了删掉这一层就行，底下的画面一点没动。

**画动画时每层画完整的样子** —— 因为播放是一帧一张图、不叠加。
如果第 2 帧想接着第 1 帧画，可以先把第 1 层复制粘贴上来，再往上加东西。

## 更新

App 支持**在线补丁**：修 bug、改文案这类小改动，不用重新下载安装包。

- **看有没有更新**：「⋯」菜单 → **设置** → 最上面会出现一张卡片，写着版本号和更新说明。
- **平时不会打扰你**：启动时偶尔查一下，有新版也**不弹窗**，只在顶栏「⋯」上加个小红点、设置那行的小字变成「· 有新版本」。
- **更新**：卡片上点「立即更新」→ 会自动把新文件拉下来 → 自动重启就是你刚下的那版。整个过程**不用卸载重装，画稿也都在**。

万一补丁有问题（比如 CDN 抽风），App 会**自己退回安装包里那套内置版本**，不会卡住打不开。想手动退出也很简单：设置 → 最底下「**回到内置版本**」。
