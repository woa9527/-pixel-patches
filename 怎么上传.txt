像素涂鸦 · 补丁上传说明
================================================================

这个文件夹里是 v1.2 的【全量快照】，第一次要全部传上去。
传完之后仓库里就有东西了、main 分支也就有了，App 那边才有东西可以更新。

（别担心体积：一共 46 个文件 313 KB，CDN 传的时候会压缩，实际下去约 78 KB。）


第一次怎么传
----------------------------------------------------------------
1. 打开  https://github.com/woa9527/-pixel-patches
   （进去应该是空的，显示 "Quick setup" / "README" 之类的提示）

2. 点右边那个绿色的  "Code"  按钮，或者直接找页面中间那一块
   → 选择 "Upload files"（也可以直接访问带 /upload/main 的那个上传页）

3. 把这三样一起拖进上传框：
       css 文件夹
       js  文件夹
       patch.json
   注意是【文件夹本身】，不是把里面的文件一个个拖出来 ——
   仓库里要保留 css/ js/ 这样的目录结构，跟本地一样。
   （新版 GitHub 支持直接拖文件夹；要是你的浏览器不支持，就先拖 patch.json，
     再用 "create new file" 一个一个手动建，或者干脆全部平铺在根目录。
     平铺也能跑，只是 patch.json 里那堆 css/xxx.css 要跟着改成 xxx.css。）

4. 页面最下面 "Commit changes" 那里，title 随便填（比如 "v1.2"），
   然后点绿色的 Commit changes。

5. 等大概 1–2 分钟，让 CDN 把新内容同步过去。


怎么确认传对了
----------------------------------------------------------------
浏览器打开这个网址：

    https://cdn.jsdelivr.net/gh/woa9527/-pixel-patches@main/patch.json

能看到一整屏 JSON（开头是 "ver": "1.2"）就说明成功了。
如果显示 404 —— 要么还没同步完（再等两分钟），要么目录结构传错了。


以后修 bug 怎么传（就两步）
----------------------------------------------------------------
不用再传全部文件了，只传改动的那一个：

1. 把新文件覆盖到仓库里对应的那个位置
   （GitHub 网页上：点进那个文件 → 右上角铅笔图标 Edit → 粘贴新内容 → Commit）

2. 把 patch.json 里的 "ver" 加一位：
       "ver": "1.2"      →      "ver": "1.2.1"
   顺手把 desc 改成这次改了啥（会显示在 App 的更新卡片上）。

   版本号随便加，只要比 App 里现在的大就行 ——
   比较方式是按点分段比数字（1.2 < 1.2.1 < 1.3 < 1.10）。


App 那边怎么用
----------------------------------------------------------------
「⋯」菜单 → 设置 → 有新版时最上面会出现一张卡片
→ 点「立即更新」→ 自己下载 + 自动重启，就好了。

不用卸载重装，画稿也不会丢。


万一出了问题
----------------------------------------------------------------
· CDN 拉不到 / 补丁有毛病 → App 会自己退回安装包里那套内置版本，不会卡住。
· 想手动退出在线补丁 → 设置 → 最下面「回到内置版本」。
· 同一版补丁如果崩过一次，App 会记住，不再自动重试。
